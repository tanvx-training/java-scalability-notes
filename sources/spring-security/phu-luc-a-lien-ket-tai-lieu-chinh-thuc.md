# Phụ lục A: Các liên kết đến tài liệu chính thức

Song hành cùng cuốn sách này, vui lòng tham khảo các liên kết sau để truy cập tài liệu chính thức của các framework mà chúng ta sử dụng:

- Spring framework: https://docs.spring.io/spring-framework/reference/index.html
- Spring Security: https://docs.spring.io/spring-security/reference/index.html
- Spring Security authorization server: https://docs.spring.io/spring-authorization-server/docs/current/api/

Trong trường hợp bạn sử dụng các dự án này với phiên bản Java 17, bạn có thể tham khảo đặc tả kỹ thuật API tại: https://docs.oracle.com/en/java/javase/17/docs/api/.

Nếu sử dụng một phiên bản Java khác, vui lòng chọn đặc tả kỹ thuật API tương ứng trong danh sách tại: https://docs.oracle.com/en/java/javase/.

Trong Chương 18, chúng ta sử dụng JUnit 5 để viết các bài kiểm thử đơn vị và kiểm thử tích hợp. Vui lòng tham khảo tài liệu hướng dẫn chính thức của JUnit 5 tại: https://junit.org/junit5/docs/current/user-guide/.
