# Kubernetes: Up and Running, 3rd Edition (Bản dịch tiếng Việt)

Bản dịch tiếng Việt của cuốn *Kubernetes: Up and Running, 3rd Edition* (Brendan Burns, Joe Beda, Kelsey Hightower, Lachlan Evenson; O'Reilly). Mỗi chương là một file Markdown; hình minh họa nằm trong thư mục [`images/`](images/).

Quy ước dịch:

- Các thuật ngữ chuyên ngành được giữ nguyên tiếng Anh (Pod, Deployment, ReplicaSet, Service, Ingress, namespace, label, annotation, container, cluster, node, `kubectl`, v.v.).
- Toàn bộ code, lệnh, tên file, kết quả terminal được giữ nguyên bản.
- Các khung *Note / Tip / Warning / Caution* được trình bày dạng trích dẫn với tiêu đề **LƯU Ý / MẸO / CẢNH BÁO / THẬN TRỌNG**.
- Ghi chú của người dịch (nếu có) được đánh dấu rõ *(Ghi chú của người dịch: ...)*.
