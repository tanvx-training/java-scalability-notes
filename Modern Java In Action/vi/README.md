# Modern Java in Action — Bản dịch tiếng Việt

Bản dịch tiếng Việt đầy đủ 21 chương của *Modern Java in Action*
(Raoul-Gabriel Urma, Mario Fusco, Alan Mycroft — Manning Publications).

Nguồn: các file PDF từng chương trong thư mục cha.

## Quy ước dịch

- **Thuật ngữ chuyên ngành giữ nguyên tiếng Anh** (stream, lambda, collector, backpressure,
  functional interface, default method, module…). Lần đầu xuất hiện trong mỗi chương có
  thể kèm giải nghĩa ngắn trong ngoặc.
- **Code giữ nguyên 100% tiếng Anh** — tên class, biến, phương thức, chuỗi, output.
  Chỉ comment trong code được dịch sang tiếng Việt.
- Chú thích đánh số dưới code trong bản gốc được chuyển thành comment ngay tại dòng code
  tương ứng.
